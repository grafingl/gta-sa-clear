## 📦 Установка

1. Скачай архив **`gta.sa.clear.7z`** со страницы [последнего релиза](https://github.com/grafingl/gta-sa-clear/releases/latest).
2. Распакуй его **поверх чистой** GTA San Andreas (с заменой файлов).
3. Запускай игру через **`gta-sa.exe`**.

> [!TIP]
> Нет игры? В папке `.bonus` лежит ярлык на загрузку чистой GTA SA, а также `appmanifest_12120.acf` — положи его в `steamapps`, и Steam увидит игру как установленную.

> [!NOTE]
> Чтобы отключить любой мод, просто удали (или переименуй с `.` в начале) его папку внутри `modloader`.

## ⌨️ Управление

| Клавиша | Действие |
|:---:|---|
| <kbd>F4</kbd> | Сохраниться где угодно |
| <kbd>R</kbd> | Перезарядка оружия |
| `HOTCOFFEE` | Чит-код: включить / выключить Hot Coffee (включён по умолчанию) |
| <kbd>Ctrl</kbd> + <kbd>M</kbd> | Чит-меню (если поставлено из `.bonus`) |

## 🎁 Бонусы — `.bonus`

Не установлены по умолчанию. Хочешь — перекинь нужное в корень игры или в `modloader`.

| Мод | Что делает |
|---|---|

| **FramerateVigilante** | Исправление багов при высоком FPS |
| **FastLoad** | Быстрый запуск игры |
| **The Challenge** | Хардкорная модификация ([страница мода](https://gtaforums.com/topic/990278-the-challenge-san-andreas/)) |
